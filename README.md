# 言語理論 中間試験 過去問＆解説デスク（R5〜R7）

PCで問題を表示しながら、iPadで手書き演習を行うための静的Webアプリです。

- **公開ページ (GitHub Pages):** https://21bebe.github.io/gengo-riron-study/

## 主な機能
- R5・R6・R7年度の過去問（全33問）を年度別・分野別・理解度別に絞り込み可能
- 「1問集中モード」と「一覧まとめモード」の切替
- ヒント → 解答（SVG状態遷移図・導出木付き）→ 詳しい解説・よくあるミス の段階的表示
- 理解度チェック（◎ / △ / ×）の自動保存（`localStorage`）
- 授業資料1〜7の定義・定理・解法手順チートシート（`C` キーで開閉）
- 左手キーボードショートカット対応（`J`/`K` 問題移動、`H`/`A`/`E` 段階開閉、`1`/`2`/`3` 理解度記録、`C` チートシート）
